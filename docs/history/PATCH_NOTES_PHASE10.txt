Added:
- scripts/release_check.py: repeatable local release verification.
- README.md: documents the new release-check command and its limitations.

Checks performed by the script:
- Required project paths are present.
- Flask, PyMuPDF (fitz), and requests import modules are available.
- All Python files outside ignored build/virtual-environment/cache directories compile.
- Common private/large-file patterns (environment files, keys, databases, and model weights) are absent from the project tree; .env.example is allowed.
- Runs `python -m unittest discover -s tests -v` unless `--skip-tests` is supplied.

Usage:
  python scripts/release_check.py
  python scripts/release_check.py --skip-tests

Limitations:
